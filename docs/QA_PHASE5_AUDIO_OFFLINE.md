## ۴. P5-T2 — کش آفلاین صوت (Cache Storage + Range برای Safari)

بر اساس ADR-8: باینری mp3 در **Cache Storage** (جدول `quran-audio-v1`)، فقط ابردادهٔ per-surah در **Dexie v5** (`audioDownloads`). SW از `generateSW` به `injectManifest` منتقل شد تا **`RangeRequestsPlugin`** (پاسخ 206 برای Safari) روی Route صوت فعال باشد.

### نتیجهٔ verification (health-check)

| مورد | نتیجه |
|---|---|
| everyayah.com (ACAO `*`) — قابل کش از صفحه و سرو توسط SW | ✅ |
| آینهٔ Maqra (HF، بعد از redirect `*`) — قابل کش | ✅ |
| CDN islamic.network — **ACAO ندارد** (preflight با Origin → 403) | ⚠️ فقط fallback آنلاین؛ قابل دانلود آفلاین نیست |
| `npm run build` (injectManifest) — `dist/sw.js` ساخته و شامل Route صوت + range | ✅ |
| ۵ تست جدید `audio-cache.test.ts` | ✅ |
