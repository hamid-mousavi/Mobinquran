# فاز صفر — تثبیت و اعتبارسنجی

## وضعیت مبنا

- متن و ترجمه‌ها در زمان اجرا از `api.alquran.cloud` دریافت و در IndexedDB ذخیره می‌شوند.
- دادهٔ اولیهٔ داخل برنامه کامل نیست؛ استفادهٔ کاملاً آفلاین پیش از دریافت داده ممکن نیست.
- صوت از `everyayah.com` پخش می‌شود و بستهٔ صوتی آفلاین ندارد.
- راهنمای تدبّر، تحلیل ادبی و پاسخ‌های AI در حال حاضر منبع/شماره صفحهٔ قابل استناد ندارند؛ نباید با عنوان تفسیر معتبر عرضه شوند.
- داده‌های کاربر فقط در مرورگر نگهداری می‌شوند و هنوز export/sync ندارند.

## کنترل‌های فنی انجام‌شده

- CI با Node 22، `npm ci`، type-check و build در GitHub Actions افزوده شد.
- build تولیدی محلی اصلاح شد تا bundle سرور نیز ساخته شود.
- Service Worker در لحظهٔ نصب، فایل‌های JS/CSS هش‌شدهٔ Vite را cache می‌کند؛ آزمون حالت هواپیما همچنان برای هر release الزامی است.
- دانلود آفلاین فقط پس از تطبیق شمار آیات هر سوره کامل ثبت می‌شود و برای دریافت‌های ناقص، توقف و تلاش مجدد دارد.
- منبع عملیاتی فعلیِ متن و سه ترجمه، API سرویس Al Quran Cloud با editions ثبت‌شده در برنامه است؛ وضعیت مجوز محتوا همچنان «در حال بررسی» نمایش داده می‌شود.
- بستهٔ داخلی `quran-core-v1.json` شامل ۶۲۳۶ آیه، متن عثمان‌طه و سه ترجمهٔ موجود در منبع عملیاتی است و هنگام شروع برنامه در IndexedDB نصب می‌شود.

## معیار پذیرش فاز صفر

1. هیچ محتوای بدون ارجاع با عنوان «تفسیر معتبر»، نقل قول یا چکیدهٔ یک تفسیر مشخص نمایش داده نشود.
2. منابع متن، ترجمه، صوت و تفسیر در رجیستر محتوا ثبت و وضعیت مجوزشان مشخص شود.
3. مسیرهای `/api/health` و `/api/ai/status` در Production پس از هر deploy بررسی شوند.
4. سناریوهای قرائت، جست‌وجو، دانلود، بوکمارک، ختم، صوت و AI روی Chrome Android و Safari iOS ثبت و نتیجه‌گیری شوند.
5. نصب PWA و اجرای مجدد پس از یک بار استفادهٔ آنلاین و سپس در حالت هواپیما آزموده شود.
