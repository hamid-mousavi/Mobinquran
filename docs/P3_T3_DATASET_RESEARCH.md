# P3-T3 — تحقیق دیتاست چیدمان ۱۵ خطی مصحف (پروتوتایپ)

> وضعیت: **دادهٔ چیدمان (quran-qcf4، MIT) دریافت و بستهٔ ۶۰۴ صفحه ساخته شد؛ پروتوتایپ `?proto=mushaf` آمادهٔ تأیید بصری است.**
> تاریخ: ۲۰۲۶-۰۹-۲۲

## مسئله

حالت مصحف ۶۰۴ صفحه‌ای فعلاً آیات هر صفحه را به‌صورت متن پیوستهٔ justify رندر می‌کند، نه چیدمان دقیق ۱۵ خطی مصحف مدینه. برای نمایش صادقانهٔ «مصحف» باید مرز خط شروع/پایان هر آیه (و ترجیحاً کلمات هر خط) از یک منبع معتبر و دارای مجوز گرفته شود.

## گزینه‌های بررسی‌شده

### گزینهٔ A — مجمع ملک فهد quran-dev
- **مکان:** `https://qurancomplex.gov.sa/quran-dev/`
- دادهٔ رسمی مصحف Hafs شامل `sura_no`, `aya_no`, **`line_start`**, **`line_end`**, `page`, `jozz`, `aya_text` است (صیغه‌های Excel/CSV/SQL/XML/JSON/PDF، رسم عثمانی یونیکد).
- **مجوز:** استفادهٔ عمومی رایگان برای برنامه‌ها (بیانیهٔ رسمی «حقوق الاستخدام»).
- **نقص:** فقط مرز خط به‌ازای آیه می‌دهد. در خطوطی که **پایان یک آیه و آغاز آیهٔ بعدی** در یک خط مشترک قرار دارند، نقطهٔ دقیق شکست کلمه را نمی‌دهد؛ یعنی چیدمان دقیق خط به‌خط از این داده به تنهایی ایجاد نمی‌شود.

### گزینهٔ B — Quranic Universal Library (QUL)
- GitHub `blueheron786/quranic-universal-library-mushaf-layouts`؛ دادهٔ SQLite با layout های ۱۴۰۵/۱۴۲۱.
- **مشکل:** فایل LICENSE ندارد — تکثیر/توزیع صریح نیست.

### گزینهٔ C — zonetecde/mushaf-layout
- GitHub `zonetecde/mushaf-layout`؛ ۶۰۴ فایل JSON با کلمات/خط.
- **مشکل:** LICENSE ندارد (404 در دانلود LICENSE).

### گزینهٔ D — quran-qcf4 (QCF v4) ✅ انتخاب‌شده
- GitHub `MohamadHajjRabee/quran-qcf4` — بانک دادهٔ QCF v4 بر پایهٔ مصحف مدینهٔ **۱۴۴۱ هجری** (خطّ عثمان طه، مجمع الملک فهد)، روايت حفص.
- محتوا: `pages/001..604.json` — **هر کلمه با `verse_key`، `position`، نوع (`word`/`end`/`surah_header`/`bismillah`/`quarter`) و `text` عربی**، به‌همراه `verses.json` و `font-map.json`.
- **مجوز: دادهٔ JSON تحت MIT License صریح** (LICENSE.md ریپازیتوری). فونت‌های QCF4 مجوز توزیع آزاد ندارند و **استفاده نمی‌شوند**.
- **چرا بهتر از A برای هدف ما:** چون کلمات هر خط را جداگانه می‌دهد، چیدمان دقیق مبتنی بر منبع اصلی (مصحف مدینهٔ ۱۴۴۱) به‌دست می‌آید — برای خطوط مشترک دو آیه هم کلمه دقیق داریم.
- Derivation note: دادهٔ پروژه از مصحف مدینهٔ ۱۴۴۱ است (نه ۱۴۴۰/چاپ اول)، و نیز یک نکتهٔ املایی مشاهده شد: `سُورَةُ االفَاتِحَةِ` (ال-ال مضاعف) در خود بانک — در صورت ادغام کامل بررسی و در OPEN_QUESTIONS ثبت می‌شود.

## پیاده‌سازی فعلی

- `scripts/generate-mushaf-layout.mjs` — دانلود و اعتبارسنجی (نوع/versre_key/text/صفحه) ۶۰۴ صفحه؛ خروجی `public/data/mushaf-layout-v1.json` (۵.۳MB، SHA-256 ثبت).
- تست `src/test/mushaf-layout.test.ts` (۶ تست) سبز.
- پروتوتایپ `?proto=mushaf`: کامپوننت `MushafPrototype` پنج صفحهٔ نمونه (۱، ۲، ۱۰۴، ۶۰۲، ۶۰۴) را با چیدمان واقعی رندر می‌کند؛ فونت: انتخابی کاربرِ اپ (پیش‌فرض عثمان‌طه).
- **اقدام پس از تأیید بصری:** ادغام در `MushafPageView` (جایگزینی متن پیوسته با chidمان خط‌به‌خط، افزودن نشانگر ربع/حزب، شمارهٔ آیهٔ کامل، حذف نسخهٔ متن-روان فقط در صورت رضایت)، به‌روزرسانی برچسب UI به «مصحف ۶۰۴ ص»، و تصمیم دربارهٔ `سُورَةُ االبَقَرَةِ` نگاشت شده.

## کارهای باقی‌مانده (پس از تأیید بصری پروتوتایپ)

1. تأیید بصری کاربر روی `?proto=mushaf`.
2. ادغام در `MushafPageView` + تست‌های به‌روز و به‌روزرسانی برچسب UI («نمایهٔ صفحه‌ای» → «مصحف»).
3. ثبت بستهٔ چیدمان در PWA precache (با حجم ~۵.۳MB) — بررسی گزینهٔ فشرده‌سازی (فشرده‌کردن کلمات بدون افت).
